# Task 263.6.4 Workload-Qualified Opportunity Tournament

## Outcome

The old `portfolio_memory` publication claim remains permanently stopped.
Task 263.6.3 was not entered and no new confirmation panel was created.

A fresh, result-blind tournament compared:

1. structured world-model / evidence-graph coherence;
2. Socratic causal, constraint, counterexample, and falsification critics;
3. external data, laboratory, or environment feedback with explicit human
   scientific responsibility.

Only `socratic-falsification` is admitted, and only to:

`development-only clean-room baseline and evaluator construction`.

This is not a novelty, effect, Research Question, confirmation, publication,
release, or submission decision.

## Why the system was not publishable

The repository already had real executions, content-addressed evidence,
clean-room replay, graph projections, reproducibility packages, and paper
building. The failed publication route exposed four distinct gaps:

- the first confirmation instrument mixed numeric and string classification
  labels;
- the repaired full workload crossed a wall-clock deadline and changed eight
  scientific trajectories;
- the repaired diagnostic effect was unfavorable;
- the consumed panel could not be made untouched again.

Task 263.6.4 therefore makes instrument, workload, objective endpoint,
independent-unit power, open resources, and human responsibility separate
noncompensating gates.

## Workload qualification

The new standalone probe uses only the Python standard library and contains
one deterministic representative kernel per mechanism family. Each track ran:

- two distinct frozen clean interpreter installations;
- planned concurrency one and two;
- one calibration repeat per interpreter/concurrency cell;
- three qualification repeats per cell;
- six calibration and eighteen qualification observations;
- 20,000 exact algorithmic work units;
- a separate 5-second CPU budget;
- a post-calibration orchestration deadline with at least eightfold slack;
- zero retries;
- exact scientific projection replay;
- tolerant runtime telemetry only.

and seeds are explicitly not independent units. The frozen sensitivity uses

## Track decisions

### Structured world model

Rejected. Kosmos, Graph of Trace, and Code as Agent Harness support structured
state and inspectability, but the live audit did not recover the official
system, a clean strong baseline, an objective incremental evaluator, complete
data/code licenses, enough independent units, or the required compute.

### External feedback

Rejected. Robin establishes a valuable lab-in-the-loop boundary and
Execution-Grounded/EurekAgent establish execution feedback and environment
engineering. The accessible execution-grounded route has only two
environments, unclear repository/data licenses, and a reported eight-H100
nanoGPT regime. Human laboratory, safety, interpretation, and publication
duties remain non-delegable.

### Socratic falsification

Admitted to development construction only. The route combines:

- AHOIS critic primitives;
- POPPER sequential falsification and Type-I discipline;
- AstaBench's Apache-2.0 harness and budget conventions;
- DiscoveryBench's ODC-By database;
- SciAgentArena's validity tasks and finding that agents execute invalid
  premises.

POPPER and SciAgentArena public repositories have no verified license, and
SciAgentArena data are gated. Their code/data cannot be copied. DiscoveryBench
gold hypotheses are natural language, so the tournament certifies only a
clean-room binary fault-evaluator specification, not an implemented objective
evaluator.
