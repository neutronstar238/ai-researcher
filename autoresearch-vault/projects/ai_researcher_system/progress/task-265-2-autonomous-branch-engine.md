## What is genuinely autonomous

The repository contains the generic research contract, not a candidate
catalogue. The model transaction first creates a portfolio frame, then one
hypothesis per assigned mechanism slot, then a complete module per candidate.
Every accepted candidate and technical replacement is persisted byte-for-byte
with its prompt, response, provider metadata, source IDs, static review,
environment, process result, and Harness episode. The orchestrator never
inserts a scientific method, edits a candidate numeric expression, or uses an
LLM self-score as evidence.

Transport retry, structured-output repair, hypothesis-contract repair, code
technical repair, and future scientific mutation are separate ledgers. A
technical repair sees synthetic probe diagnostics and traceback only; it sees
zero official development score. Up to six exact model revisions per branch
are allowed under an explicit worst-case transaction budget.

## Versioned non-scientific adapter

`row-major-flat-v1` separates generic tensor movement from candidate science.
Candidates receive nested values, an authoritative shape, and row-major flat
numeric leaves. They return one flat derivative value per leaf; the Harness
reconstructs the nested container using the fixture-owned shape. It cannot
pad, truncate, change, smooth, or replace numeric values.

## Failed live protocols retained as evidence

- v18 used two-point spatial axes. For quadratic libraries this makes
  `x² = x`, so one candidate's normal equations were rank-deficient and
  returned zero independently of input. The exact candidate passed all five
  probes when the fixture alone was changed to three coordinate levels.
- v19 rejected a 5,225-node source under an arbitrary 5,000-node limit. The
  exact source passed static and all capability checks under the bounded 6,000
  limit.
- v20 reached 7/8 but one branch exhausted four technical revisions after a
  matrix-orientation error and an unchanged response. The official-score-blind
  technical budget is now at most six revisions.
- v21 first exhausted a source-domain hypothesis contract because stateless
  repair omitted the prior payload; late repair now carries the prior response
  and all already-public domain-valid source IDs. A later v21 attempt showed
  that line count is not a security/resource measure: an 850-line, 36.9-KB,
  3,949-node source passed all probes unchanged after the line-count gate was
  removed.
- v22 passed the complete live contract in about 5 minutes 39 seconds. A
  terminal replay replaced provider and network functions with hard failures
  and still reloaded the identical package hash.

These were pre-development capability calibrations. No official outcome was
observed while changing the Harness, so they cannot be confused with
benchmark-score tuning.
