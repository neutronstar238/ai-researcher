# 素数结构与计算数论

把本技能作为独立方法消息使用。它提供研究路径，不指定结论，也不构成文献或实验
证据。

## 形成单一可检验问题

1. 从题目中选择一个可操作构念，例如局部间隙结构、剩余类偏差、素性判定成本或
   有限尺度可预测性。
2. 明确一个主假设、一个主要结局和一个分析单位。不要把熵、密码学、深度学习、
   Green--Tao 定理和黎曼猜想同时堆成一个项目。
3. 写出支持、反驳和无法区分三种结果。有限范围计算只能检验有限尺度命题，不能
   证明或否定黎曼猜想、孪生素数猜想等开放问题。

## 构造数据与对照

- 用确定性筛法生成主数据，并用可核验序列库作交叉检查；记录上界、实现和随机种子。
- 将自然数位置上的素数指示序列与素数间隙序列分开，避免混用不同样本空间。
- 至少比较两类对照：保持密度的随机对照，以及保持边际分布但打乱次序的置换对照。
  需要时再加入周期或合数结构对照。
- 不把重叠窗口或同一序列的多个随机种子当作独立科学样本。优先按不相交数值区间
  分块，并报告区间间稳定性。

## 选择方法

- 信息论路径可使用块熵、排列熵或 Lempel--Ziv 复杂度，但必须校正稀疏密度、
  非平稳性和有限样本偏差。
- 间隙路径可比较经验分布与预先声明的随机基线，并用置换或分块 Bootstrap 给出
  不确定性；不要假定间隙独立同分布。
- 算法路径应区分素性判定与整数分解，统一输入位长、实现语言、硬件和正确性测试。
- 机器学习仅作为可证伪探针：采用时间/数值顺序外推切分，与常数、经验分布和简单
  自回归基线比较；预测失败同样是有效结果。

## 预注册与可行性

1. 预先冻结数据范围、主要指标、对照、停止规则和多重比较策略。
2. 先做普通工作站可完成的小规模预实验，用它估计内存、耗时和统计方差，再决定
   是否扩大数据规模。
3. 没有预实验时，只写预期方向和判定规则，不写具体效应值、显著性或“已经发现”。
4. 所有引用只能来自调用方提供的真实目录；技能中的方法名不是引用来源。

## 结果解释

- 与密度匹配随机对照有差异，只说明所选统计量检测到有限尺度结构。
- 原序列与置换序列有差异，才支持顺序结构而非仅边际分布解释。
- 结论限定到数据范围、编码方式和指标；同时给出最强替代解释与下一步决定性实验。
