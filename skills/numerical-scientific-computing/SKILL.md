# 数值科学计算可靠性

本技能约束科学计算的数值推理，不预设哪个算法应当获胜。所有系统属性、参数、阈值和结果都必须来自当前冻结制品或由模型明确标记为前瞻性设计选择。

## 数值审查流程

1. 明确输入对象及量纲：状态、时间或空间网格、导数目标、噪声条件、训练与测试边界。系统名称不能替代这些事实。
2. 拆分误差来源：采样误差、导数估计误差、特征缩放、矩阵病态、优化误差、阈值选择和积分或预测误差分别记录。
3. 检查 ODE 与 PDE 边界。不得把不同维度、网格、边界条件或导数算子混为同一独立单位；跨类型汇总必须分层报告。
4. 为待测数值组件建立等预算对照，固定数据、特征库、优化器、停止规则和评分，只改变一个数值步骤。
5. 在揭盲前固定稳定性诊断，例如条件数代理、残差结构、系数路径、扰动放大率或网格收敛；诊断必须与主要效果指标不同。
6. 设计有限敏感性网格。范围必须来自公开边界或明确的前瞻性选择，禁止看完测试结果后扩展搜索。
7. 同时报出误差和失败。超时、非有限值、不可解矩阵与空模型不能从分母中静默删除。
8. 给出资源上界：最大特征数、拟合次数、内存、单元时间和总调用数；若无法在正式预算内完成，只能降级为待研究问题。
9. 只有当数值诊断随干预按预注册路径变化、负对照不变化且主要结局一致响应时，才允许把结果解释为目标数值机制。

## 推理回执要求

在 reasoning 中依次核对量纲与 scope、误差分解、唯一变化组件、稳定性诊断、敏感性边界、失败保留和资源上界。正式结论只能引用冻结事实、真实文献或后续测量，reasoning 本身不是证据。

## 立即否决

- 从系统名称猜测刚性、混沌性、边界条件或方程形式。
- 同时更换导数估计、特征库和优化器后归因其中一个组件。
- 用测试集选择阈值、网格或停止点。
- 删除数值失败后再比较平均性能。
- 只报告主要误差而没有独立稳定性诊断。
- 资源预算开放式增长或没有确定上界。
