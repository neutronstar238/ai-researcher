# Agent记忆评估

本技能只规定如何研究记忆机制，不提供研究结论、评分答案或隐藏评测信息。开放探索可自由提出记忆策略；只有晋级、执行和结论阶段才要求下述证据闭合。

## 划分记忆职责

1. 将精确原始记录定义为只追加、可溯源的主权层；纠错通过新事件表达，不覆盖旧字节。
2. 将摘要、索引、链接、当前结论和Dreaming视为可删除重建的派生层；允许压缩、失效和遗忘。
3. 将进入当前模型请求的内容视为有预算工作记忆；不得把“磁盘中存在”混同为“模型本轮可见”。
4. 分别记录摄取、修订、选择、暴露、消费和任务终点，按完整状态轨迹判断正确性。

## 先定义可证伪主张

把模糊的“记忆更好”拆成至少一项可独立否定的主张：

- 保留：原始字节能否在长时间后精确复核。
- 召回：目标记录能否在有限上下文预算内被选中。
- 更新：新事实能否替代陈旧依赖且保留修订链。
- 抗污染：不可信记录能否被隔离而不改变可靠结论。
- 实际消费：召回内容是否进入后续真实请求，并由结构化动作明确引用。
- 任务收益：处理臂是否在盲化终点上优于预算匹配对照。

保存、召回、显式消费和任务收益是四个不同门，不得互相代替。

## 设计决定性挑战

至少覆盖以下不同失败模式，不用同一模板换随机种子虚增独立样本：

1. 早期信息在离开短期窗口后才变得关键。
2. 旧结论被后续事实纠正，且旧依赖容易残留。
3. 两个来源互相冲突，需要按来源、时间或授权范围处理。
4. 工具返回空结果或失败，系统应改变策略而非捏造证据。
5. 恶意、越权或错误记忆试图进入召回与行为路径。

独立分析单位是独立任务或场景；同一场景的seed、重复轮次和多指标只能作为单位内重复。

## 构造预算匹配对照

优先使用配对消融，并保持模型、公开刺激、token、工具、墙钟、失败计费和评分过程一致。逐层比较：

- 固定动作流程与模型自选动作。
- 自适应循环与自适应但无主权原始召回。
- 能力已暴露与能力被实际使用。
- 原始层保留与派生层策略改变。

处理臂只改变一个已声明的记忆机制。若同时改变检索器、提示词、预算或工具，不得作因果归因。

## 证明实际消费

不要用动作正文关键词或模型自述单独判定。证据链至少绑定：

1. 早期输入的精确原始记录、来源和内容哈希。
2. Dreaming或召回的前序状态、确定性选择和excerpt哈希。
3. 召回反馈在后续模型请求中的精确消息投影与传输回执。
4. 模型原始JSON中的结构化消费声明：record、payload、selection、excerpt及中文应用说明。
5. 终态动作、任务状态和盲化评分。

结构化声明只能证明可追溯的显式消费；只有预算匹配的外部终点差异才能支持收益主张。

## 控制策略演化

允许主Agent把是否检索、检索数量、是否Dreaming、是否二次查询和是否采用派生计划作为上下文相关动作。新策略只能先成为候选：

1. 绑定父版本、触发失败、改动范围和预期机制。
2. 在冻结轨迹或影子流量上与旧策略预算匹配比较。
3. 同时检查任务收益、污染率、陈旧依赖、成本和停止质量。
4. 仅在外部终点改善且安全门不变时申请提升；保留回滚。

原始写入、项目隔离、权限、证据、许可和发布政策不得进入可学习动作空间。不得用同一模型的自评分作为唯一奖励。

## 调节记忆依赖而非全开全关

把派生记忆依赖作为可审计实验因素，而不是默认越多越好：

1. 开放发散可以采用低派生依赖或近似重新开始，以检测既有经验是否压制新假设。
2. 纠错、引用复核、复现和晋级应提高精确原文与来源约束，但不得把派生摘要提升为原始事实。
3. 至少比较无记忆、有限派生记忆和主权原始召回三个档位；保持模型、任务、预算和工具不变。
4. 同时报告收益与锚定代价：输出相似度、错误传播、错位经验重放、新方向多样性和外部终点。
5. 若提高记忆依赖只增加历史复述而未改善盲化终点，应判定为锚定或无效，不得写成长期记忆收益。

依赖档位只控制读取和工作上下文，不改变原始记录的保留、权限或可审计性。

## 输出审计

输出至少说明：记忆层职责、可证伪主张、独立分析单位、单一干预、冻结项、挑战类型、预算、盲化终点、状态轨迹回放、消费证据链、污染反例、无法判定条件和未获授权事项。Skill内容本身不是文献、实验结果、科学证据或发布批准。
