# 稀疏动力学辨识

把本技能作为方法约束使用，不把其中的检查项复制成结论。所有具体构念、目标系统、干预、阈值和预期方向都必须由当前模型依据当前证据自行产生。

## 工作流

1. 先锁定证据边界。核对计划、数据面板、运行器、环境、条件和候选单元是否可比；不完整单元只用于记录缺失，不能进入效果归因。
2. 建立可观测事实账本。分别列出公开数据画像、逐系统效果、同数据类型关联、跨谱系矩阵和文献事实。系统名称只是标识符，不能据此补写方程结构、刚性、混沌性或物理机制。
3. 拆开辨识流水线。至少区分导数估计、候选特征库、缩放或归一化、稀疏优化器、阈值或超参数选择、模型选择与最终评分。多项同时变化时，只能形成待检验问题，不能归因单个组件。
4. 先写证据矛盾，再写构念。矛盾必须跨至少三个完整可比系统，或在至少四个同类型系统中成立；不得从单个极端系统、总体排名或未校正的最大相关直接推出机制。
5. 设计单组件反事实。明确处理臂与对照臂，二者只能相差一个目标组件；其余数据、切分、代码路径、预算、随机种子和评分规则全部冻结。不得只写“做消融”而不写两臂差异。
6. 同时设计三类辨别手段：
   - 负对照：不触发目标机制，但能暴露相同的实现扰动或混杂。
   - 敏感性对照：在揭盲前固定少量强度或边界，检查方向是否稳定，不得事后挑选。
   - 正交诊断：独立于主损失，直接测量所声明的中间路径；不能把主指标换名重用。
7. 使用正确分析单位。以冻结 estimand 指定的独立系统为单位；condition 与 seed 是系统内重复，不能冒充独立样本。把目标解释、替代解释和无法判定三类结果都写进揭盲前判据。
8. 给出资源有界的最小诊断。固定一次成对比较，不进行开放式超参数搜索；明确特征数量、拟合次数、时间和内存的确定上界，并与正式单元预算核对。
9. 对照完整文献目录。区分“现有方法未解决同一识别问题”与“仓库尚未实现某功能”。只有前者且能产生跨系统知识时才保留为科研机会。

## 推理与输出契约

在模型的 reasoning 通道按以下顺序推理，并把简短、可审计的决策依据写入结构化阶段产物：

1. 引用的事实编号及其 scope。
2. 被排除的两种以上解释及排除依据。
3. 唯一被操纵组件和冻结项。
4. 负对照、敏感性对照和正交诊断各自读取什么。
5. 三分结果盲判据与独立分析单位。
6. 最小诊断的资源上界。
7. 与真实文献的差异及仍不确定之处。

reasoning 内容只作为过程审计，不作为科学证据；正式主张必须回指冻结事实、真实文献或后续实验结果。

## 立即否决条件

- 从系统名称猜测未观测机制。
- 混合 ODE 与 PDE 后把数据类型差异解释成机制。
- 把探索性相关、单系统差异或联合混杂的候选差异写成因果结论。
- 处理臂与对照臂同时改变多个流水线组件。
- 缺少具体替代解释、负对照、正交诊断或无法判定分支。
- 把 condition-seed 数量当作独立样本量。
- 用小型 sentinel 的预算否决正式单元，或不给出正式单元内的资源上界。
- 只修复代码、接口、超时或评分契约，却声称得到可发表科学知识。
